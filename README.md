# COU3306 - Data Structures and Algorithms
## Practical Guide - Lesson 06: Employee Management System

### 📌 Overview
This repository contains the Java implementation of an **Employee Management System** using an unordered object array data structure. Developed as part of the **COU3306 - Data Structures and Algorithms** course at **The Open University of Sri Lanka (OUSL)**.

### 🛠️ Features & Methods Implemented
- **`insert(String employeeName, int age, double salary)`**: Adds a new `Employee` object to the array ($O(1)$ time complexity).
- **`search(String searchName)`**: Performs a linear search to find an employee by name ($O(N)$ time complexity).
- **`remove(String searchName)`**: Searches for an employee and removes them by shifting remaining elements ($O(N)$ time complexity).
- **`display()`**: Iterates and prints the full employee roster with salaries.

### 📂 File Structure
- `src/Employee.java` - Class defining employee attributes (`employeeName`, `age`, `salary`).
- `src/Company.java` - Management class encapsulating the object array operations.
- `src/Main.java` - Test suite demonstrating insertion, searching, deletion, and display operations.
